T&C for users

User terms for the Activities website.

These terms govern the use of the Activities platform by parents, guardians and general site visitors. Review with counsel before production launch.

Last updated:

1. Platform scope

Activities currently provides discovery information, planning tools and reminder support for classes, camps, workshops and related content.

2. Listing information

We aim to present accurate information, but schedules, prices, locations and availability may change. Users should verify key details directly with the provider before enrolling.

3. No guaranteed enrollment

Discovery through the website does not guarantee admission, seat availability or any provider outcome.

4. Reminders and calendar files

Reminder and calendar features are convenience tools only. Users are responsible for checking final schedules, venue changes and provider communications.

5. Acceptable use

Users must not misuse the site, interfere with operations, upload harmful content or impersonate others.

6. Contact

Questions about these terms can be sent to hello@activitieshub.in.
